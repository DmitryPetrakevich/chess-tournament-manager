ChessDraw works with the official FIDE Dutch 2026 rules using the BBP Pairings 6.0 engine.

This source archive does not include third-party executables.
Run ..\Install-BBPPairings.ps1 on Windows to download upstream version 6.0.0.
Or download bbpPairings.exe from:
https://github.com/BieremaBoyzProgramming/bbpPairings/releases/tag/v6.0.0
and put it in this folder.

The build script copies the executable to dist\engines automatically.
