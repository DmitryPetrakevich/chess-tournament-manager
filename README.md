# ChessDraw — приложение для шахматных турниров

Исходный проект **C# / Windows Forms / .NET 8** для Windows 10/11 (x64). Интерфейс на русском.

## ТУСУР — шахматная жеребьёвка: обновление 26 ноября 2026 года

Локальный менеджер университетских турниров с основными сценариями Swiss-Manager, без интеграции с Chess-Results. Тёмная тема, оформление ТУСУР, навигация по этапам турнира и статус завершения.

PDF оформляется как альбомный отчёт A4: шапка ТУСУР, сведения о турнире, таблицы с выделением первых трёх мест, отдельные страницы туров, повтор заголовков на продолжениях и номера страниц. Длинные ФИО переносятся, коэффициенты сохраняют до двух знаков после запятой. Печать в Microsoft Print to PDF проверена на реальном восьмистраничном отчёте.

Рейтинг нового участника по умолчанию — **1000**. При массовом вводе отсутствие рейтинга, пустое поле или 0 также дают 1000. Ранее сохранённые явные значения не пересчитываются. Для создания демонстрационного PDF при самопроверке: `ChessDraw.exe --self-test --quiet --pdf-demo`.

Добавлены массовый ввод участников (ФИО;рейтинг либо два столбца из Excel), таблица результатов по турам с соперниками и цветами, отмена заявленного пропуска. Результат партии сохраняется сразу после выбора: переключение тура или турнира не теряет введённые значения.

Исправлены предел вклада BYE в коэффициенты, обработка технических результатов в круговой системе и изменение стартовых номеров при неудачной первой жеребьёвке. Бухгольц исключён из ранжирования и отчётов круговых турниров. «Победы за доской» не включают технические победы и BYE. При загрузке и сохранении проверяется структура турнира; повреждённые данные восстанавливаются из резервной копии, если она исправна.

## Исправление версии 1.3

- Устранён сбой запуска «Невозможно задать свойство ReadOnly ячейки до того, как она будет добавлена в строку» при восстановлении сохранённого турнира с BYE (включая свободный тур кругового турнира).
- Ячейка результата BYE сначала добавляется в строку `DataGridView`, затем заполняется и блокируется для редактирования. Автоматические очки за швейцарский BYE сохраняются.
- Формат `tournaments.json` не менялся: ранее созданные турниры не требуется удалять или переносить.
- Для установки заново распакуйте архив в отдельную папку, запустите `Build-Windows.cmd`, затем `dist\ChessDraw.exe`. Если ошибка повторяется, пришлите файл `%LOCALAPPDATA%\ChessDraw\startup-errors.log`.

## Что реализовано

- Создание, редактирование, удаление турниров и локальное автоматическое сохранение.
- Регистрация по ФИО, необязательный рейтинг; стартовый номер при первой швейцарской жеребьёвке определяется рейтингом, затем алфавитным порядком ФИО (титулы не вводятся), после чего фиксируется.
- Швейцарская система (голландская система ФИДЕ, редакция от 1 февраля 2026 года) через специализированный внешний движок **bbpPairings 6.0.0**. Приложение не заменяет его собственной упрощённой жеребьёвкой.
- Круговая система: один или два круга, чётное и нечётное количество участников, парные цвета во втором круге.
- Ввод результатов: 1:0, 0:1, ½:½, техническая победа каждой стороны, обоюдная неявка 0:0; **автоматический BYE (+1 очко без ручного ввода)** при нечётном числе активных участников швейцарского тура, заявленный пропуск тура с 0 или ½ очка; снятие с швейцарского турнира.
- В таблице пар рядом с каждым игроком показаны его очки **до начала выбранного тура** (результаты тура не изменяют эти значения).
- Таблица: очки, Бухгольц, усечённый Бухгольц (Cut-1), Бергер (Sonneborn–Berger), число побед. Учитываются поправки при несостоявшихся играх согласно разделу 16 положения ФИДЕ о дополнительных показателях от 1 марта 2026 года.
- Сохранение на диск: `%LOCALAPPDATA%\ChessDraw\tournaments.json`, резервная копия `.bak`, атомарная запись.
- Экспорт `.xlsx` с двумя листами (турнирная таблица и жеребьёвка/результаты); экспорт PDF через стандартный Windows-принтер **Microsoft Print to PDF**.

## Как получить EXE на Windows (проще всего)

1. Установить **.NET 8 SDK** (не только Runtime): https://dotnet.microsoft.com/download/dotnet/8.0
2. Распаковать архив и запустить `Build-Windows.cmd` двойным щелчком **при доступном Интернете**.
3. Скрипт попробует скачать bbpPairings 6.0.0 с GitHub и соберёт **обычную, не автономную** версию EXE, не скачивая пакет `Microsoft.WindowsDesktop.App.Runtime.win-x64` с NuGet. Если загрузка движка не удалась, сборка всё равно продолжится.
4. Открыть `dist\ChessDraw.exe`. Для **швейцарской** системы положить `bbpPairings.exe` в папку `dist\engines`.

> Стандартная сборка требует установленного .NET 8 Windows Desktop Runtime; **.NET 8 SDK его включает**. Если нужен полностью автономный EXE, запустите PowerShell-команду `powershell -ExecutionPolicy Bypass -File .\Build-Windows.ps1 -SelfContained`; для неё потребуется скачать большой пакет Runtime, и при нестабильном интернете возможна ошибка `unexpected EOF`.
>
> Чтобы пропустить даже попытку загрузки движка с GitHub: `powershell -ExecutionPolicy Bypass -File .\Build-Windows.ps1 -SkipEngineDownload`.

### Альтернативно: Visual Studio 2022

Откройте `ChessDraw/ChessDraw.csproj`, запустите проект `F5`. Перед использованием швейцарской системы положите `bbpPairings.exe` из официального релиза в `ChessDraw/bin/Debug/net8.0-windows/engines/` либо запустите `Install-BBPPairings.ps1` и скопируйте файл оттуда. Для выпуска воспользуйтесь `Build-Windows.cmd`.

### Альтернативно: GitHub Actions

При публикации исходников в репозитории GitHub откройте **Actions → Windows build → Run workflow**. Задание соберёт WinForms на Windows и предоставит архив `ChessDraw-Windows-x64` с `ChessDraw.exe` и папкой `engines`.

## Как пользоваться

1. Нажать **«+ Создать»**, указать название и систему (для швейцарской также число туров и начальный цвет).
2. Добавить всех игроков, при необходимости указать рейтинги. После начала жеребьёвки нельзя добавлять или удалять игроков, но можно изменить их ФИО.
3. Для швейцарской системы нажимать **«Следующий тур»**, открывать вкладку «Жеребьёвка и результаты», вносить результат каждой партии, сохранять, затем переходить к следующему туру. Игрок с автоматически назначенным BYE сразу получает +1 очко; вводить результат ему не нужно. Если игрок не участвует в следующем туре, до жеребьёвки выделить его на вкладке «Участники» и нажать **«Пропуск тура»**.
4. Для круговой системы нажать **«Создать расписание»**, после чего появятся все туры; можно заполнять их результаты в любом порядке.
5. На вкладке «Турнирная таблица» доступны таблица и экспорт Excel/PDF.

## Самопроверка

В папке `dist` выполните `ChessDraw.exe --self-test` (или `--self-test --quiet` без окон). Проверяются круговые турниры на 2–20 игроков, контрольные расчёты очков и коэффициентов, TRF, XML внутри Excel, восстановление базы, интерфейс и швейцарские турниры через настоящий bbpPairings. Для тестов нужен движок в `engines` рядом с EXE. Результат сохраняется в `self-test-results.txt`, снимок окна — в `ui-preview.png`; при ошибке код завершения 1 и подробности в `self-test-failure.txt`. Тесты используют отдельную временную базу и не меняют пользовательские турниры. Это не заменяет проверки по полному набору судейских примеров ФИДЕ.

## Важные ограничения

- Обновлённая сборка находится в `dist\ChessDraw.exe`; для стандартной версии нужен .NET 8 Windows Desktop Runtime. Сборка и самопроверки выполнены на Windows.
- Для **швейцарской системы** обязательно нужен внешний `bbpPairings.exe`. Если он отсутствует, приложение выдаст ошибку, а не построит псевдо-ФИДЕ жеребьёвку.
- Параметры начального рейтинга и стартовые номера после первой жеребьёвки фиксируются. Для официального рейтингового турнира понадобятся дополнительные сведения (идентификаторы ФИДЕ, федерация, титулы, контроль времени, отчёт TRF и проверка аккредитации ПО). Этот проект — турнирный менеджер для клубных соревнований, **не аттестован ФИДЕ как программа для официальных рейтинговых турниров**.
- Экспорт PDF зависит от присутствия «Microsoft Print to PDF». На некоторых конфигурациях Windows драйвер может показать собственный диалог для выбора имени файла, несмотря на переданный путь.
- Порядок дополнительных показателей: для швейцарской — очки, Бухгольц Cut-1, Бухгольц, Бергер, победы за доской; для круговой — очки, Бергер, победы за доской. При полном равенстве порядок определяется стартовым номером. Промежуточные коэффициенты пересчитываются по мере ввода результатов.
- Участник кругового турнира, который не явился на партию, должен получить техническое поражение через выбор результата. Функция «Снять / вернуть» предусмотрена только для швейцарских турниров.
- Жеребьёвка и расчёт показателей с техническими результатами требуют проверки арбитром на пограничных случаях, особенно в турнирах, планируемых для рейтингового отчёта.

## Структура

- `ChessDraw/Models` — модели турнира, участника, тура и партии
- `ChessDraw/Services` — файловое хранилище, генератор круговой системы, интеграция с BBP, расчёт показателей
- `ChessDraw/Exports` — экспорт Excel (OpenXML без сторонних пакетов) и PDF (стандартный Windows-принтер)
- `ChessDraw/UI` — графический интерфейс WinForms и диалоги
- `Build-Windows.cmd`, `Build-Windows.ps1` — самостоятельная Windows-сборка
- `Install-BBPPairings.ps1` — получение внешнего движка из исходного GitHub-репозитория

## Если двойной щелчок по ChessDraw.exe ничего не делает

Запустите `Diagnose-Start.cmd` **из корня распакованного проекта** после сборки.
Скрипт проверит установленный .NET Runtime, запустит `dist\ChessDraw.dll` через хост `dotnet` и сохранит файл `startup-diagnostics.txt` рядом со скриптом.
В новой версии исключения при инициализации главного окна перехватываются и записываются в `%LOCALAPPDATA%\ChessDraw\startup-errors.log`, даже если интерфейс не смог открыться.
Если отсутствует `Microsoft.WindowsDesktop.App 8.x` в `dotnet --list-runtimes`, установите Windows Desktop Runtime 8 x64.
**Внимание:** диагностический скрипт ожидает завершения приложения — если окно ChessDraw открылось нормально, закройте его, чтобы диагностика закончилась.
